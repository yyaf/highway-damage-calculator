# 高速公路路产损坏赔偿计算器

基于广东省官方赔偿标准的微信小程序，提供损坏项目快速查询、数量选择及赔偿金额自动计算功能。

## 功能

- 内置粤交路〔1998〕38 号及粤公路函〔2020〕352 号共 160 余项赔偿标准，2020 年价格自动覆盖同名项目
- 关键词搜索路产项目，按使用频次智能排序，点击即添加
- 数量支持加减调节及手动输入，实时计算小计与合计
- 合计金额同时显示阿拉伯数字与中文大写（财务规范格式）
- 一键复制赔偿清单至剪贴板，生成规范文本报告
- 自动记录计算历史，支持回顾与再次复制
- 每个项目标明文件来源（38号 / 352号），一目了然
- 按实计算项目支持自定义输入单价，自动参与金额计算
- 复制清单金额去除多余小数位，格式简洁清晰

## 技术栈

微信小程序原生框架（WXML + WXSS + JS），无第三方依赖，纯前端实现。

## 快速开始

1. 克隆仓库
```bash
git clone https://github.com/yyaf/highway-damage-calculator.git
```

2. 打开微信开发者工具，导入项目目录

3. 在开发者工具中点击「预览」生成二维码，手机微信扫码即可体验

## 项目结构

```
├── app.js / app.json / app.wxss   # 小程序入口与全局配置
├── data/prices.js                 # 赔偿标准数据（~160 项，14 大类）
├── utils/
│   ├── calculator.js              # 购物车计算 + 文本报告 + 中文大写金额
│   ├── usage-tracker.js           # 使用频次追踪
│   └── history.js                 # 历史记录读写
├── pages/
│   ├── calculator/                # 计算页：搜索 + 已选清单 + 底部合计栏
│   ├── standards/                 # 标准页：标准文件列表
│   ├── standard-items/            # 标准详情：只读浏览
│   └── profile/                   # 我的：历史记录 + 版本信息
└── images/                        # TabBar 图标
```

## 数据说明

赔偿标准数据依据：

- 《损坏公路路产赔偿标准》粤交路〔1998〕38 号
- 《广东省损坏公路路产赔偿指导标准》粤公路函〔2020〕352 号

同名项目以 2020 年价格为准，「按实计算」项目支持手动输入自定义单价。
