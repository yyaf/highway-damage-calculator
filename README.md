# 高速公路路产损坏赔偿计算器

基于广东省官方赔偿标准的微信小程序，提供损坏项目快速查询、数量选择及赔偿金额自动计算功能。核心逻辑配备 223 个单元测试，零依赖纯前端实现。

## 功能

- 内置粤交路〔1998〕38 号、粤交路〔1999〕263 号及粤公路函〔2020〕352 号共 280 余项赔偿标准，三份标准项目独立展示，同名项目分别标注来源
- 三份标准间项目自动关联，100% ID 匹配覆盖率（7 策略级联匹配算法）
- 关键词搜索路产项目，按使用频次智能排序，点击即添加
- 数量支持加减调节及手动输入，实时计算小计与合计
- 合计金额同时显示阿拉伯数字与中文大写（财务规范格式）
- 一键复制赔偿清单至剪贴板，生成规范文本报告
- 自动记录计算历史，支持回顾与再次复制
- 每个项目标明文件来源（38号 / 263号 / 352号），一目了然
- 按实计算项目支持自定义输入单价，自动参与金额计算
- 复制清单金额去除多余小数位，格式简洁清晰
- 自定义 TabBar，三页切换流畅
- 223 个单元测试覆盖核心逻辑（node:test），零回归

## 技术栈

微信小程序原生框架（WXML + WXSS + JS），无第三方依赖，纯前端实现。

## 快速开始

1. 克隆仓库
```bash
git clone https://github.com/yyaf/highway-damage-calculator.git
```

2. 打开微信开发者工具，导入项目目录

3. 在开发者工具中点击「预览」生成二维码，手机微信扫码即可体验

```
│   ├── calculator.js              # 购物车计算 + 文本报告 + 中文大写金额
│   ├── calc-id-matcher.js         # ID 匹配工具（7 策略级联，100% 覆盖率）

│   ├── calc-id-matcher.test.js    # ID 匹配算法测试（56 用例）

└── images/                        # TabBar 图标
```

## 数据说明

赔偿标准数据依据：

- 《损坏公路路产赔偿标准》粤交路〔1998〕38 号
- 《增补公路路产赔偿项目标准》粤交路〔1999〕263 号
- 《广东省损坏公路路产赔偿指导标准》粤公路函〔2020〕352 号

同名项目在不同标准中分别以独立条目存在，各自标注文件来源，「按实计算」项目支持手动输入自定义单价。
